# Dental Data Research

> Phase 2 of Dental Scope. Which openly licensed 3D data can power a dental anatomy explorer, and what has to be built ourselves.
> Research date: 2026-09-25. Licences were read at the source listed; re-verify before each release.

## 1. Requirements recap

| Need | Why |
|---|---|
| Full adult dentition in anatomical position | Arch-level exploration, tooth numbering |
| Maxilla, mandible, gingiva, surrounding skull & muscles of mastication | Context: mouth → jaw → dentition |
| Internal tooth anatomy (enamel, dentin, cementum, pulp, canals) | Tooth-level dissection — the core feature |
| Neurovascular structures (inferior alveolar, lingual, superior alveolar) | Clinically central in dentistry |
| TMJ (condyle, fossa, disc) | Requested category |
| Licence that allows redistribution in an open-source web app | Hard requirement |
| Browser-friendly size after processing | < ~10 MB first load |

|---|---|---|---|---|---|---|---|

| **Z-Anatomy** (L. A 2025 systematic review of openly accessible oral-maxillofacial imaging datasets found that only ~62 % of 105 datasets state reuse terms at all, which matches our experience: licence clarity is the main blocker, not data availability.

## 3. Gap analysis → decisions

| Gap | Decision for v1 | Provenance label shown in UI |
|---|---|---|
| Third molars (1, 16, 17, 32) missing in BodyParts3D | Derived from the adjacent second molar: copied, scaled ~0.92, moved distally along the arch curve and slightly rotated | `derived` |
| Internal tooth anatomy | **Generated by our own pipeline** from each BodyParts3D tooth: signed-distance field → tissue layers (enamel/dentin/cementum/PDL by depth & crown/root level) → pulp chamber by inner offset → canals traced along each detected root's medial axis, canal count per root from a typical-configuration table | `modeled` (schematic, derived from real external shape) |
| Crown / root split | Cervical line detected from the cross-section profile (cervical constriction) | `modeled` |
| Alveolar bone | Partitioned from maxilla/mandible: bone surface within a few mm of the roots | `derived` |
| Nerves & vessels | Z-Anatomy centrelines (trigeminal → V2/V3 → alveolar, mental, lingual, buccal, infraorbital nerves; external carotid → maxillary → dental arteries, facial artery; jugular, retromandibular, maxillary, facial veins), fitted onto the BodyParts3D jaws. Dental branches end at the tooth apices | `atlas` |
| Superior alveolar nerves, inferior alveolar vein, pterygoid plexus | Not in Z-Anatomy: tubes along landmark paths, joined to the atlas paths (V2 / infraorbital nerve, the plexus → maxillary vein) | `schematic` |
| TMJ disc | Schematic biconcave disc placed between the condyle and articular fossa | `schematic` |
| Primary dentition, salivary glands, tongue | Not in the v1 data subset. Categories exist in the registry and appear as "not yet modeled" | — |

Every structure in the registry carries a `provenance` of `source | derived | modeled | atlas | schematic`, recorded in the manifest. Nothing schematic is presented as measured anatomy.

## 4. Licensing consequences

- BodyParts3D is **CC BY-SA 2.1 JP** → all processed geometry in `public/models/` is distributed under CC BY-SA 2.1 JP (share-alike), with the required credit:
  "BodyParts3D, © The Database Center for Life Science, licensed under CC Attribution-Share Alike 2.1 Japan."
- Our own generated geometry (schematic nerves, discs) is produced by code in this repo; because internal layers are derived from BodyParts3D shapes, we distribute the **whole model set** under CC BY-SA 2.1 JP for simplicity.
